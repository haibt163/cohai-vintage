# Cô Hai Vintage — Phase 2 fixed

This package is designed to replace the default Next.js root `app` with the Cô Hai Vintage app.

IMPORTANT: The original Phase 2 asset selection was based on the current `website_1fe948e5` WordPress uploads, which are Astra starter/demo assets. They are NOT genuine Cô Hai Vintage product images. This fixed package intentionally contains no copied WordPress images. Genuine Cô Hai media will be recovered separately from the correct WordPress source in Phase 3.

Copy `app`, `components`, and `lib` into the root of `C:\Users\XPS\cohai-vintage`, replacing existing files when prompted. Then run `npm run dev`.
