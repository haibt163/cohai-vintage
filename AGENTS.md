This is the Cô Hai Vintage website rebuild.

Stack: Next.js 16 + TypeScript + App Router.

The original site was WordPress/Elementor/Astra.

The goal is NOT to reproduce Elementor. Build a clean, modern, maintainable Next.js implementation.

The current authoritative source is this repository.

Original WordPress assets are under public/assets/original.

Do not use Astra starter/demo imagery as Cô Hai product imagery.

Do not commit SQL dumps, wp-config.php, passwords, API keys, or Bluehost backup archives.

Preserve genuine Cô Hai content and media where appropriate.

Before making major architectural changes, inspect the existing implementation.

Run the relevant checks after changes.

Never replace original media merely because a generic stock image looks better.
